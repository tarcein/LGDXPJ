# 데이터베이스 객체 정의서

`01_요구사항정의서.md`의 문장에서 데이터베이스에 저장할 가치가 있는 명사를 추출해 **개체(테이블)**와 **속성(컬럼)**으로 분류한 것이다. 속성 옆의 `PK`는 기본키, `FK`는 외래키, `UK`는 유니크 제약을 뜻한다. 실제 구현(`backend/app/db.py`)을 그대로 반영했다.

## A. 가족·구성원·자녀

| 개체 | 속성 |
|---|---|
| **family_group** (가족 그룹) | id `PK`, name, plan, created_at |
| **family_location** (가족 활동 지역) | family_id `PK,FK`, city, district, updated_at |
| **family_member** (가족 구성원) | id `PK`, family_id `FK`, name, role, status, is_owner, created_at |
| **child** (자녀) | id `PK`, family_id `FK`, name, age_label, photo_storage_path, photo_mime_type, photo_updated_at |

## B. 인증·초대

| 개체 | 속성 |
|---|---|
| **family_invite_code** (재사용 초대 코드) | family_id `PK,FK`, code_hash `UK`, expires_at |
| **family_invite_link** (1회성 초대 링크) | code_hash `PK`, family_id `FK`, created_by_member_id `FK`, expires_at, created_at, join_count, max_uses, revoked_at |
| **family_session** (로그인 세션) | token_hash `PK`, family_id `FK`, member_id `FK`, expires_at, last_seen_at |

## C. 일정

| 개체 | 속성 |
|---|---|
| **personal_schedule** (개인 일정) | id `PK`, family_id `FK`, member_id `FK`, title, starts_at, ends_at, has_end_time, kind, external_source, external_id, recurrence_id, recurrence_rule |
| **child_schedule** (아이 일정) | id `PK`, family_id `FK`, child_id `FK`, title, category, starts_at, ends_at, has_end_time, source, created_at, recurrence_id, recurrence_rule |

## D. 돌봄 처리 파이프라인

| 개체 | 속성 |
|---|---|
| **care_intake** (돌봄 정보 원문) | id `PK`, family_id `FK`, child_id `FK`, raw_content, input_type, created_at |
| **care_item** (구조화된 돌봄 항목) | id `PK`, family_id `FK`, intake_id `FK`, child_id `FK`, child_schedule_id `FK`, item_type, title, detail, starts_at, confidence, status, created_at |
| **care_assignment** (돌봄 배정) | id `PK`, family_id `FK`, item_id `FK`, assignee_id `FK`, requested_by_member_id `FK`, status, source, created_at, responded_at, completed_at, note, reminder_sent_at |
| **care_exception** (예외 상황) | id `PK`, family_id `FK`, assignment_id `FK`, reason, alternative_member_id `FK`, status, created_at |
| **care_handoff** (돌봄 인수인계) | id `PK`, family_id `FK`, assignment_id `FK`, from_member_id `FK`, to_member_id `FK`, briefing, status, acknowledged_at |

## E. 알림·설정

| 개체 | 속성 |
|---|---|
| **notification** (알림) | id `PK`, family_id `FK`, member_id `FK`, title, body, level, is_read, action_type, action_id, created_at |
| **family_data_permission** (정보 공개 권한) | member_id `PK,FK`, scope `PK`, is_allowed |
| **notification_preference** (알림 수신 설정) | member_id `PK,FK`, app_enabled, daily_digest_enabled, device_enabled |

## F. 사용량·AI

| 개체 | 속성 |
|---|---|
| **daily_usage** (일일 사용량) | family_id `PK,FK`, day `PK`, feature `PK`, amount |
| **assistant_message** (AI 채팅 메시지) | id `PK`, family_id `FK`, member_id `FK`, role, content, created_at |
| **plan_preview** (요금제 미리보기) | family_id `PK,FK`, enabled |

## G. 긴급·미디어·디바이스

| 개체 | 속성 |
|---|---|
| **emergency_request** (긴급 도움 요청) | id `PK`, family_id `FK`, assignment_id `FK`, requested_by_member_id `FK`, reason, status, claimed_by_member_id `FK`, created_at, resolved_at |
| **media_asset** (미디어 자산) | id `PK`, family_id `FK`, child_id `FK`, assignment_id `FK`, uploaded_by_member_id `FK`, kind, file_name, mime_type, content_base64, caption, created_at |
| **device_alert_outbox** (가전 알림 대기열) | id `PK`, family_id `FK`, member_id `FK`, assignment_id `FK`, title, body, status, created_at |
| **push_device_token** (푸시 토큰) | token `PK`, family_id `FK`, member_id `FK`, platform, created_at, updated_at |

## H. 혜택·구독·결제

| 개체 | 속성 |
|---|---|
| **member_benefit_location** (구성원별 혜택 검색 지역) | family_id `PK,FK`, member_id `PK,FK`, city, district, updated_at |
| **family_subscription** (가족 구독) | family_id `PK,FK`, provider, customer_key `UK`, billing_key, status, amount, current_period_start, current_period_end, next_billing_at, cancel_at_period_end, canceled_at, renewal_failure_count, last_renewal_error, last_auth_key_hash, created_at, updated_at |
| **payment_transaction** (결제 거래) | order_id `PK`, family_id `FK`, provider, amount, status, payment_key, approved_at, created_at |

## I. 캘린더 연동

| 개체 | 속성 |
|---|---|
| **calendar_oauth_state** (캘린더 인증 상태) | state `PK`, family_id `FK`, member_id `FK`, provider, expires_at, return_url |
| **calendar_connection** (캘린더 연결) | family_id `PK,FK`, member_id `PK,FK`, provider `PK`, access_token, refresh_token, expires_at, connected_at, synced_at |

| 그룹 | 개체 수 |
|---|---:|

| B. 인증·초대 | 3 |
| C. 일정 | 2 |
| D. 돌봄 처리 파이프라인 | 5 |
| E. 알림·설정 | 3 |
| F. 사용량·AI | 3 |
| G. 긴급·미디어·디바이스 | 4 |
| H. 혜택·구독·결제 | 3 |
| I. 캘린더 연동 | 2 |
| **합계** | **29** |

> 참고: `notification.action_type`/`action_id`는 알림이 가리키는 대상(배정, 인수인계, 예외 등)이 매번 달라지는 다형성(polymorphic) 참조라서 실제 FK 제약은 걸지 않았다. `daily_usage`처럼 속성이 전부 키에 묶여 있는 개체는 별도의 서술형 속성이 거의 없는 "사실(fact) 테이블"에 가깝다.
