# AI 가족 운영 에이전트 — 비기능 요구사항 명세서

> 본 문서는 `PRD_MVP_AI가족운영에이전트.md`, `유스케이스다이어그램.md`, `유스케이스명세서.md`, `기능요구사항명세서.md`를 근거로 시스템이 만족해야 할 품질 기준과 적용 시점을 정의합니다.

## 4) 비기능 요구사항

| ID | 기능명 | 설명 | 적용시점 |
|---|---|---|---|
| NFR-001 | 텍스트 구조화 응답 속도 | 사용자가 텍스트로 돌봄 정보를 등록하면 Family Inbox 구조화 결과는 전체 요청의 95%에서 3초 이내 제공되어야 한다. | 알파 테스트 |
| NFR-002 | OCR 처리 성능 | 가정통신문 등의 사진을 등록하면 OCR 처리 및 정보 구조화 결과는 전체 요청의 95%에서 5초 이내 제공되어야 하며, 문자 인식 정확도는 90% 이상이어야 한다. | 알파 테스트 |
| NFR-003 | 일정 충돌 감지 속도 | 개인 일정 등록 또는 변경이 완료된 후 돌봄 일정과의 충돌 판정 결과는 전체 요청의 95%에서 60초 이내 생성되어야 한다. | 알파 테스트 |
| NFR-004 | 알림 전달 속도 | 일정 등록·역할 조율·인수인계·돌봄 완료 등 주요 이벤트가 발생하면 ThinQ 앱 또는 TV 알림은 전체 요청의 95%에서 5초 이내 전달되어야 한다. | 베타 테스트 |
| NFR-005 | 동시 사용 처리 성능 | 가족 구성원 최대 8명이 동시에 서비스를 사용하더라도 초당 50건 이상의 요청을 처리해야 하며, 오류율은 1% 미만이어야 한다. | 베타 테스트 |
| NFR-006 | 가족 데이터 암호화 | 가족 일정, 자녀 정보, 사진 및 특이사항 데이터는 전송 시 TLS 1.2 이상, 저장 시 AES-256 수준으로 암호화되어야 한다. | 베타 테스트 |
| NFR-007 | 가족 데이터 접근 통제 | 가족방 초대를 수락하지 않았거나 해당 가족방에 속하지 않은 사용자는 가족 데이터에 접근할 수 없어야 하며, 미인가 접근 성공률은 0%여야 한다. | 알파 테스트 |
| NFR-008 | 사용자 인증 보안 | 로그인은 OAuth 2.0 또는 OIDC 표준을 준수해야 하며, 비밀번호 로그인을 제공하는 경우 2단계 인증 기능을 지원해야 한다. | 베타 테스트 |
| NFR-009 | 정보 공개 권한 통제 | 구성원별 정보 공개 권한 설정에 따라 개인 일정과 가족 정보의 조회 범위를 제한해야 하며, 권한 검증 테스트 통과율은 100%여야 한다. | 알파 테스트 |
| NFR-010 | 아동 개인정보 보호 | 자녀 사진과 건강·특이사항 등 아동 관련 정보는 개인정보보호법과 아동 개인정보 처리 기준에 따라 관리되어야 하며, 개인정보 영향평가를 연 1회 실시해야 한다. | 베타 테스트 |
| NFR-011 | 개인정보 열람·정정·삭제 | 사용자는 본인과 자녀의 개인정보에 대한 열람·정정·삭제를 요청할 수 있어야 하며, 삭제 요청은 접수 후 영업일 기준 5일 이내 처리되어야 한다. | 베타 테스트 |
| NFR-012 | 제3자 정보 제공 제한 | 가족 데이터는 사용자의 명시적 동의 없이 제3자에게 판매하거나 제공해서는 안 되며, 외부 반출 이력은 연 1회 이상 점검되어야 한다. | 베타 테스트 |
| NFR-013 | 서비스 가용성 | 서비스의 월간 가용성은 99.5% 이상이어야 하며, 월간 누적 중단 시간은 3.6시간 이하여야 한다. | 베타 테스트 |
| NFR-014 | 외부 연동 장애 대응 | 캘린더 또는 ThinQ 연동에 실패하더라도 사용자 입력 데이터가 유실되어서는 안 되며, 지수 백오프 방식으로 최대 3회 재시도해야 한다. | 베타 테스트 |
| NFR-015 | 알림 전송 장애 대응 | 앱 또는 TV 알림 전송에 실패하면 실패 상태를 기록하고 재시도해야 하며, 재시도 후 알림 누락률은 5% 미만이어야 한다. | 베타 테스트 |
| NFR-016 | 돌봄 정보 등록 편의성 | 사용자는 별도 교육 없이 3단계 이내, 평균 1분 이내에 돌봄 정보 등록을 완료할 수 있어야 하며, 사용성 테스트 완료율은 90% 이상이어야 한다. | 알파 테스트 |
| NFR-017 | 한국어 음성 인식 정확도 | 개인 일정 및 특이사항의 음성 입력은 한국어 자연어 명령을 인식해야 하며, 음성 인식 오류율(WER)은 10% 이하여야 한다. | 알파 테스트 |
| NFR-018 | 역할별 알림 문구 | 알림 내용은 수신자의 역할과 필요한 행동을 기준으로 요약되어야 하며, 알림 1건의 문구는 평균 100자 이내여야 한다. | 알파 테스트 |
| NFR-019 | 모바일 접근성 | 모바일 서비스는 WCAG 2.1 AA 수준의 접근성 기준을 준수해야 하며, 자동 접근성 진단 통과율은 95% 이상이어야 한다. | 알파 테스트 |
| NFR-020 | 고령 사용자 알림 인지성 | TV 알림은 고령 사용자도 주요 내용을 쉽게 인지할 수 있도록 큰 글자와 명확한 상태 표현을 제공해야 하며, 사용성 테스트에서 알림 내용 인지 성공률은 90% 이상이어야 한다. | 베타 테스트 |
| NFR-021 | TV 알림 명도 대비 | TV 화면의 알림 텍스트와 배경 간 명도 대비비는 WCAG 2.1 AA 기준인 4.5:1 이상이어야 한다. | 알파 테스트 |
| NFR-022 | 결제 정보 보안 | 결제 및 구독 처리는 안전한 PG 결제 표준을 준수해야 하며, 카드 원본정보는 시스템에 저장하지 않아야 한다. | 베타 테스트 |
| NFR-023 | 유료 기능 접근 통제 | 무료 플랜 사용자가 긴급 도움 요청, TV 알림, 모음ZIP 등 유료 기능에 우회 접근할 수 없어야 하며, 접근 제어 테스트 통과율은 100%여야 한다. | 알파 테스트 |
| NFR-025 | 모음ZIP 사진 접근 통제 | 모음ZIP에 저장된 자녀 사진은 해당 가족방에 초대되어 참여 중인 구성원만 접근할 수 있어야 하며, 권한 외 접근 차단율은 100%여야 한다. | 알파 테스트 |
| NFR-026 | AI 채팅 사용량 집계 | AI 채팅의 토큰 사용량은 대화 완료 후 1초 이내 반영되어야 하고 집계 오차율은 0%여야 하며, 최초 사용 시점부터 24시간 단위의 사용량 갱신 성공률은 100%여야 한다. | 알파 테스트 |
| NFR-027 | 유료 기능 안내 명확성 | 무료 사용자가 유료 기능에 접근하면 해당 기능과 제공 혜택을 50자 이내로 명확히 안내해야 하며, 관련 화면은 UX 검토를 통과해야 한다. | 알파 테스트 |
| NFR-028 | OCR 무료 사용량 집계 | 무료 플랜의 OCR 등록 횟수는 등록 완료 후 1초 이내 반영되어야 하고 집계 오차율은 0%여야 하며, 매일 00:00 초기화 성공률은 100%여야 한다. | 알파 테스트 |

> NFR-024는 개인정보 최소화를 위해 돌봄 동선 및 위치정보 수집 기능이 서비스 범위에서 제외됨에 따라 결번으로 유지합니다.
