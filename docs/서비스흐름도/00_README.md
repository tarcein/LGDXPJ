# 서비스 흐름도 (MVP 핵심 흐름)

> 본 폴더는 `기능요구사항명세서.md`를 근거로, MVP 기준 핵심 서비스 흐름을 Mermaid flowchart로 작성한 결과물입니다.

## 범위 설정 기준

기능요구사항명세서의 9개 카테고리 중 아래와 같이 범위를 정했습니다.

| 포함 여부 | 카테고리 | 사유 |
|---|---|---|
| ✅ 포함 | 1. 계정·가족 기반 | 모든 흐름의 선행 조건 (온보딩) |
| ✅ 포함 | 2. 개인 일정 등록 | 무료 핵심 기능 (수기 등록 중심) |
| ✅ 포함 | 3. 돌봄 정보 등록 (Family Inbox) | PRD MVP Phase 1 핵심 기능 |
| ✅ 포함 | 4. 가족 역할 조율 (Role Match) | PRD MVP Phase 1 핵심 기능 |
| ✅ 포함 | 5. 예외 상황 대응 (Exception Care) | 무료 자동 충돌 감지 경로 포함, 서비스 핵심 가치 |
| ✅ 포함 | 6. 돌봄 인수인계 (Care Handoff) | 특이사항 입력·위치 기록 등 최근 확정된 핵심 흐름 |
| ✅ 포함 | 7. 돌봄 완료 확인 | Pain 1(재확인 불안) 직접 해소, 필수 종결 단계 |
| ✅ 포함 | 8. 알림 제공 | 앱 알림(무료)은 전 흐름의 필수 연결 고리 |
| ❌ 제외 | 9. 부가 서비스 (돌봄 공백 예측·패밀리 앨범·돌봄 제도 안내) | 명시적 유료 기능, MVP 범위 밖 |

**유료 확장 요소 처리 방식**: 음성 입력(UC-01a), 긴급 도움 요청(UC-04b), 가전 연동 알림(UC-07a)은 무료 핵심 흐름 속에서 "분기점"으로만 짧게 표시하고, 세부 처리 로직은 그리지 않았습니다. (해당 기능 자체가 유료라 MVP 핵심 흐름의 본줄기가 아니기 때문)

## 무료 사용량 한도 (흐름도 내 표시)

| 기능 | 무료 한도 | 초과 시 |
|---|---|---|
| 사진(OCR) 돌봄 정보 등록 | **1일 2회** | 유료 전환 안내 (텍스트 입력은 계속 무료) |
| AI 채팅 | **1일 10,000 토큰** (입력+출력 합산, 매일 자정 초기화) | 유료 전환 안내 (자정 초기화 후 재사용 가능) |

> 메시지 "횟수"가 아닌 "토큰 소모량"을 기준으로 설계해, 짧은 질문과 긴 대화를 공정하게 구분합니다(Claude 등 생성형 AI 서비스의 사용량 기반 정책 참고). 두 수치 모두 기획서 작성자가 설정한 초기 기준값이며, 운영 데이터로 조정될 수 있습니다.

## 작성 규칙

- **사용자 행동**(파란색)과 **시스템 처리**(회색)를 구분
- **외부 시스템**(주황색, 캘린더 시스템·LG ThinQ 플랫폼)은 별도 표시
- **분기/판단**(노란색 마름모), **시작·종료**(초록색)
- 세부 UI 입력 동작(버튼 위치, 필드 단위 입력 등)은 제외하고 핵심 처리 단위로만 표현

## 파일 목록

| 파일 | 흐름 | 관련 기능 요구사항 |
|---|---|---|
| `01_온보딩_가족설정.mmd` | 가족 그룹 생성 및 설정 | FR-001~004 |
| `02_개인일정등록.mmd` | 개인 일정 등록 | FR-005~007 |
| `03_돌봄정보등록_FamilyInbox.mmd` | 돌봄 정보 등록 | FR-008~010 |
| `04_가족역할조율_RoleMatch.mmd` | 가족 역할·할일 조율 (1차 조율) | FR-011~013 |
| `05_예외상황대응_ExceptionCare.mmd` | 예외 상황 대안 추천 및 승인 (2차 조율) | FR-014~020 |
| `06_돌봄인수인계_CareHandoff.mmd` | 돌봄 인수인계 (특이사항·위치기록) | FR-021~025 |
| `07_돌봄완료확인.mmd` | 돌봄 완료 현황 확인 | FR-026~028 |
| `08_알림제공.mmd` | 일정·케어 현황 알림 제공 | FR-029~032 |
| `09_통합_전체흐름도.mmd` | 위 8개 흐름을 서브그래프로 묶어 한 화면에서 보는 통합도 | FR-001~032 |

각 `.mmd` 파일은 Mermaid Live Editor(mermaid.live) 또는 Mermaid를 지원하는 마크다운 뷰어에 그대로 붙여넣어 렌더링할 수 있습니다.

> `09_통합_전체흐름도.mmd`는 01~08의 내부 로직을 축약해 하나의 큰 파이프라인으로 연결한 개요용 다이어그램입니다. 세부 분기(모든 예외 흐름 등)는 각 개별 파일을 참고하세요. 홈 대시보드를 허브로 5개 핵심 흐름이 병렬로 뻗어나가고 하단 "알림 발송"에서 합류하는 구조로, 사용자 행동/시스템 처리를 색상 대신 **노드 유형**(처리·AI분석·DB·분기·종료)으로 구분해 한 화면에서 보기 쉽도록 별도 스타일을 적용했습니다.

## PNG 이미지

각 `.mmd`와 동일한 이름의 `.png` 파일을 함께 제공합니다(예: `09_통합_전체흐름도.png`). Mermaid CLI로 렌더링한 결과이며, 최종 산출물 문서에 그대로 삽입해 사용할 수 있습니다. `.mmd` 파일을 수정한 경우, 아래 명령으로 다시 렌더링하세요.

```bash
npx -y @mermaid-js/mermaid-cli -i 09_통합_전체흐름도.mmd -o 09_통합_전체흐름도.png -b white -w 1600
```
