# 2026-09-17 Figma 화면·기능·API 매핑

## 적용 원칙

- 기준 파일은 루트의 `목업이미지.fig`이며, `기능(413:8)` 페이지의 모바일 프레임과 `화면설계서(580:2)`의 SCR 정의를 함께 확인했다.
- Figma의 여러 프레임은 각각 별도 페이지가 아니라 **같은 화면의 상태**인 경우가 많다. 코드에서는 URL을 늘리지 않고 API 응답과 로컬 UI 상태에 따라 기본·빈 화면·로딩·오류·완료 상태를 전환한다.
- 기존 일정, OCR, 역할 배정, 인수인계, 가족, 결제 API는 유지하고 화면 구조와 진입 흐름을 Figma 기준으로 맞춘다.
- Figma의 OS 상태바(작은 시계·통신·배터리)는 앱 UI가 아니므로 제거한다. 잠금화면의 큰 시계는 잠금화면 콘텐츠이므로 유지한다.
- Figma의 플랜 가격 9,900원보다 제품 결정 사항인 **월 7,900원**을 우선한다.
- 기존 제품 결정에 따라 Figma의 “모음ZIP” 명칭은 **모음ZIP**으로 표시한다.

## 전체 진입과 화면 전환

```text
ThinQ 홈
 ├─ 이지윤 홈 ▼ → ThinQ 홈 선택 시트
 │                    ├─ 이지윤 홈 → ThinQ 홈
 │                    └─ 민솔이네 집 → 서비스 로딩 → ZIPPY 홈
 └─ 더 알아보기
      ├─ 가족방 있음 → 서비스 로딩 → ZIPPY 홈
      └─ 가족방 없음 → 홈 선택 시트 → 지금 만들기 → 온보딩

ZIPPY
 ├─ 상단 민솔이네 집 ▼ → ThinQ 홈 선택 시트
 ├─ 홈
 ├─ 케어
 ├─ 일정
 ├─ 가족
 └─ 더보기
```

모바일 브라우저의 뒤로가기는 화면 기록을 따라가며, 오버레이가 열린 상태에서는 사진 상세·일정 시트·완료 시트를 먼저 닫는다. 초대 링크는 `?invite=코드&role=역할`로 온보딩 초대 미리보기에 바로 진입한다.

## 실제 API와 임시 목업 경계

### 현재 API에 연결됨

- 가족방 생성·참가·반복 사용 초대 링크, 구성원 관리와 권한
- 개인·아이 일정의 단건/반복 등록, 수정, 삭제
- Google·Outlook OAuth 연결 설정과 동기화 요청
- 알림장 OCR, 음성 전사, AI 채팅과 일정 변경 도구
- 담당자 추천, 요청, 수락·거절, 최종 확정, 긴급 요청
- 완료·인수인계, 사진 업로드, 날짜 폴더, 삭제
- 알림 읽음과 관련 화면 이동
- 지역별 아이 돌봄 제도·기관·지원 기준
- 토스 결제, 구독 취소 예약과 재개, 개발자 플랜 전환

### 네이티브 또는 외부 SDK 전까지 목업

- ThinQ 앱 자체 홈과 실제 ThinQ 계정/홈 전환
- iOS Live Activity·Android 잠금화면/알림 액션
- TV·정수기·냉장고 등 가전으로 보내는 실제 푸시
- 지도·내비 SDK의 실시간 좌표와 도착 감지
- 준비물 구매처·배송시간 추천
- 장기 돌봄 공백 예측과 평소 담당 기본 규칙 저장

목업 부분은 화면에서 실제 데이터인 것처럼 저장하지 않는다. 관련 버튼은 현재 앱 내부 미리보기나 기존 일정/배정 화면으로만 연결한다.

## 모바일 규격

- 디자인 기준 프레임은 `393 × 852`이며, 430px 이하에서는 기기 너비와 `100dvh`를 사용한다.
- 데스크톱 개발 보기에서도 393 × 852 프레임을 유지해 Figma와 비교할 수 있다.
- 앱 상단에는 OS 상태바를 그리지 않는다. 하단바는 safe-area를 반영한다.
- 시트는 화면 아래에서 열리고, 배경 탭·이전 버튼으로 닫힌다.
- 상단 가족명은 버튼이며 언제든 ThinQ 홈 선택 화면으로 돌아간다.

## 검증 기준

1. ThinQ 홈 → 홈 선택 → 민솔이네 집 → 로딩 → ZIPPY 홈이 이어진다.
2. ZIPPY 상단 가족명을 누르면 ThinQ 홈 선택 시트가 열린다.
3. 다섯 하단 탭의 순서, 아이콘, 활성 색상이 Figma와 일치한다.
4. OCR → 확인 → 아이 일정 저장 → 담당 추천 → 요청 → 수락 → 확정이 이어진다.
5. 완료 체크 → 특이사항 음성/수기/사진 → 다음 담당자 인계와 모음ZIP 저장이 이어진다.
6. 날짜 선택 → 일정 목록 → 추가/수정/삭제와 반복 등록이 동작한다.
7. Free/Pro 전환, 월 7,900원 결제, 구독 취소 예약과 재개가 동작한다.
8. 모바일 뒤로가기가 앱 화면 기록 또는 열린 오버레이를 처리한다.
