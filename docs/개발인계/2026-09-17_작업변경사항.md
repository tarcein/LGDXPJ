# 2026-09-17 작업 변경사항

기준일: 2026-09-17  
대상 저장소: `LGDXPJ`  
기준 브랜치: `main`

## 1. 작업 요약

Figma 화면과 `family-care-ui` 참고 소스를 기준으로 ZIPPY 모바일 UI를 전면 정리했다. 기존 가족방, 일정, 돌봄 배정, OCR, AI, 앨범, 혜택, 결제 기능은 유지하면서 화면 구조와 실제 API 연결을 보강했다.

핵심 변경은 다음과 같다.

- 캘린더를 모바일 화면 너비에 맞게 확대하고 일정 표시 방식을 개선했다.
- `일정 등록`과 `루틴 등록`을 별도 흐름으로 분리했다.
- 루틴의 요일, N일마다, 월간, 특정일 반복을 실제 저장 기능과 연결했다.
- 하드코딩된 가족·일정·예외 케어 표시를 실제 가족방 데이터 중심으로 변경했다.
- ThinQ Home, AI 어시스턴트, 공통 하단바와 플로팅 버튼의 디자인을 통일했다.
- Google·Outlook 캘린더, 토스 결제, 공공 돌봄 데이터와 기존 가족 돌봄 API를 연결했다.

## 2. 프론트엔드 UI 변경

### 2.1 공통 모바일 화면

- Figma 기준 모바일 프레임과 safe area를 반영했다.
- 실제 휴대폰에서는 목업용 OS 상태바를 숨기고 콘텐츠 여백을 다시 조정했다.
- 공통 하단바와 AI 플로팅 버튼을 주요 화면에서 유지했다.
- 카드, 버튼, 모달, 바텀시트, 빈 화면의 색상과 간격을 통일했다.
- 전체 글자 크기를 높이고 더보기·돌봄 공백 영역의 너비와 줄바꿈을 조정했다.
- 모바일에서 상단·하단 여백 때문에 콘텐츠가 비어 보이던 문제를 보완했다.

### 2.2 캘린더

- Figma `일정10` 계열 화면을 참고해 월간 캘린더를 전체 너비로 확대했다.
- 월 이동, 날짜 선택, 일정 색상 구분, 선택 날짜의 상세 목록을 추가했다.
- 한 날짜에 일정이 여러 개여도 누락되지 않도록 날짜 상세 화면에서 전체 목록을 표시한다.
- 캘린더의 `+` 버튼을 누르면 `일정 등록`과 `루틴 등록`을 먼저 선택한다.
- 뒤로가기처럼 보이던 캘린더 버튼을 제거하고 별도의 캘린더 연동 안내 버튼을 배치했다.
- Google·Outlook 연결 화면은 개인 일정 연동 기능으로 분리했다.

### 2.3 일정 등록

- 병원, 약속, 학교 행사처럼 한 번만 발생하는 일정을 등록한다.
- 아이 일정과 본인 일정을 구분한다.
- 날짜, 시작 시간, 선택적 종료 시간, 일정 종류를 입력한다.
- 저장 전 기존 가족 일정과의 시간 충돌 여부를 보여준다.
- 등록된 일정은 캘린더와 홈 화면에 실제 API 데이터로 표시된다.

### 2.4 루틴 등록

- 학원, 운동, 정기 회의처럼 반복되는 일정을 별도 화면에서 등록한다.
- 기존 상단 진행 단계와 설명 영역을 제거하고 폼이 화면을 더 넓게 사용하도록 변경했다.
- `X` 버튼은 이전 단계로 이동하지 않고 등록 화면을 바로 닫는다.
- 다음 반복 방식을 지원한다.

  - 요일 반복
  - N일마다 반복
  - 매월 특정일 반복
  - 사용자가 고른 특정 날짜 반복

- 반복 시작일과 종료일을 지정할 수 있다.
- 반복 일정은 서버에서 날짜별 일정으로 확장하며 같은 `recurrence_id`로 묶는다.
- 현재 수정·삭제는 반복 묶음 전체가 아니라 선택한 일정 한 건에만 적용한다.

### 2.5 홈과 ThinQ Home

- ZIPPY 홈은 등록된 실제 일정, 준비물, 담당 상태만 표시하도록 정리했다.
- 일정이 없을 때 임의의 사람이나 일정 대신 빈 상태 안내를 표시한다.
- ThinQ Home은 고정 이미지 한 장이 아니라 헤더, 서비스 배너, 평면도, 즐겨찾기 제품, 하단 메뉴로 나누어 구성했다.
- ThinQ 홈 선택 화면은 원래 ThinQ 배경을 유지한 채 가족방 진입 화면을 띄운다.
- 우측 상단 프로필에는 현재 로그인한 구성원 이름의 첫 글자를 표시한다.
- ZIPPY 서비스 배너와 AI 플로팅 버튼에 동일한 메인 로고를 사용한다.
- 어시스턴트 로고의 별 모양을 제거하고 원형 안에서 중앙 정렬했다.

### 2.6 온보딩과 가족 관리

- 온보딩의 `엄·할·아` 형태 임시 역할 아이콘을 제거했다.
- 가족방 생성, 참여, 자녀 등록, 초대 흐름을 유지했다.
- 구성원 목록은 서버에 저장된 실제 가족방 데이터만 사용한다.
- 로그아웃하면 현재 세션을 정리하고 온보딩 화면으로 이동한다.
- 주돌봄자 이전, 구성원 내보내기, 가족방 나가기에 권한 검증을 적용했다.

### 2.7 기록함과 사진 저장

- `모음ZIP` 명칭을 `모음ZIP`으로 변경했다.
- 사진을 날짜별로 묶고 상세 확대, 다운로드, 본인 사진 삭제를 지원한다.
- 돌봄 완료 사진도 인수인계와 기록함에 함께 연결한다.
- iPhone Safari에서는 지원 가능한 경우 공유 시트를 열어 `사진에 저장`할 수 있게 하고, 지원하지 않는 환경에서는 기존 다운로드를 사용한다.

## 3. 백엔드 및 데이터 변경

### 3.1 실제 데이터 연결

- 홈, 캘린더, 가족 구성원, 돌봄 배정, 예외 상황을 `/api/bootstrap`과 관련 API 데이터로 표시한다.
- 예시용 김태준·이순자 같은 고정 구성원을 화면 데이터로 사용하지 않는다.
- 돌봄 공백은 확정된 돌봄 항목 중 담당자가 없는 항목을 기준으로 계산한다.
- 개인 일정을 등록했을 때 기존 배정 돌봄과 충돌하면 실제 예외 케어 항목을 생성한다.
- 대체 가능한 구성원이 있을 때만 예외 케어 대안을 제안한다.

### 3.2 반복 일정

- 개인 일정과 아이 일정 API에 `repeat_dates`를 추가했다.
- 요일 반복은 `repeat_days`와 `repeat_until`을 사용한다.
- N일마다, 월간, 특정일 반복은 계산된 날짜 배열을 `repeat_dates`로 전달한다.
- 반복 날짜는 시작일부터 최대 1년 범위로 제한한다.
- 중복 날짜는 제거하고 날짜 순서대로 저장한다.

### 3.3 돌봄·알림 흐름

- 아이 일정 등록 후 가능한 가족 구성원을 추천한다.
- 담당 요청, 수락·거절, 주돌봄자 최종 확정 흐름을 연결했다.
- 일정 변경으로 기존 배정이 깨지면 재배정 필요 알림과 대체 후보를 만든다.
- 미응답 요청에는 앱 알림을 생성하고 Pro 가족은 가전 알림용 outbox 기록을 남긴다.
- 긴급 돌봄 요청은 직접 입력과 음성 입력을 지원한다.
- 완료 메모와 사진을 다음 담당자 인수인계로 전달한다.

### 3.4 AI·OCR

- AI 어시스턴트가 가족 일정, 아이 일정, 담당 배정, 알림, 저장 지역을 문맥으로 사용한다.
- 사용자가 명확하게 요청한 경우 개인 일정 또는 아이 일정을 실제로 등록·변경한다.
- 알림장 사진 OCR 결과에서 일정과 준비물을 분리한다.
- OCR 검토 화면에서 혼란을 주던 신뢰도 문구를 제거하고 원문 확인과 수정 기능은 유지했다.
- AI 대화 기록은 구성원별로 분리하고 사용량은 가족방 단위로 관리한다.

## 5. 결제와 요금제

- Pro 월 구독료를 `7,900원`으로 통일했다.
- Pro 안내 화면 안에서 토스 결제수단과 약관 영역이 펼쳐지도록 구성했다.
- 결제 성공 시 가족 플랜과 기능 권한을 Pro로 갱신한다.
- 구독 취소 시 즉시 Free로 전환하지 않고 결제 기간 종료일까지 Pro를 유지한다.
- 기간 종료 전 자동 갱신을 다시 켤 수 있다.
- AI 채팅은 가족방 단위로 Free `50,000` 토큰, Pro `200,000` 토큰의 일일 한도를 적용한다.
- OpenAI API가 반환한 입력·출력 합산 사용량을 DB에 누적하고, 채팅 화면의 잔여량과 진행바에 즉시 반영한다.
