### 2.9 AI 채팅·음성·OCR

- AI 채팅은 `/api/assistant/chat`, 대화 복원은 `/api/assistant/history`에 연결했다.
- 음성 질문은 파일 선택창을 열지 않고 `MediaRecorder`로 마이크를 직접 녹음해 `/api/assistant/voice`로 보낸다.
- 인수인계 음성은 `/api/audio/transcribe`에 `purpose=HANDOFF_NOTE`로 보낸다.
- OpenAI 키 미설정, 크레딧 소진, 키 거부, 요청 제한을 서로 다른 오류 코드와 안내로 구분한다.
- 알림장 사진 OCR은 실제 파일, 아이 ID, 촬영·앨범 출처를 서버에 전송한다.
- OCR 성공분만 무료 일일 사용량에 포함하고 실패는 사용 횟수를 차감하지 않는다.
- AI가 담당자를 임의 확정하지 않으며 배정·긴급 요청 등 상태 변경은 사용자 승인을 거친다.
- 별도 파인튜닝이나 신규 모델 학습은 아직 하지 않았다. 현재는 가족방 데이터 컨텍스트, 구조화 프롬프트, 규칙 기반 추천을 조합한다.

- 현재 공공데이터 응답은 기준연도 `2020`, 데이터 갱신일 `20260413`, 소득 기준 18건, 건강보험료 기준 151건이다. 화면에도 이 값을 그대로 표시한다.

### 2.11 DB와 PostgreSQL

- `DATABASE_URL`이 있으면 PostgreSQL, 없으면 로컬 SQLite를 사용하는 연결 계층을 추가했다.
- 기존 SQLite 데이터를 PostgreSQL로 복사하는 `backend/scripts/migrate_sqlite_to_postgres.py`를 추가했다.
- 아이 일정, 반복 일정, 미디어, 지역, 캘린더 OAuth 상태와 연결 정보 등을 저장하도록 스키마를 확장했다.
- 주요 신규 테이블은 `family_location`, `child_schedule`, `media_asset`, `calendar_oauth_state`, `calendar_connection`이다.
- 알림에 `action_type`, `action_id`, 배정에 `requested_by_member_id`, 인수인계에 `special_note` 등을 추가했다.
- 운영 데이터 이전 여부는 마이그레이션 실행 로그와 PostgreSQL 행 수를 별도로 확인해야 한다. 스크립트가 존재한다는 사실만으로 실제 운영 데이터 이전 완료를 의미하지 않는다.

### 2.12 로컬·휴대폰 실행 지원

- Vite 개발 서버를 `0.0.0.0:5173`에서 실행해 같은 Wi-Fi 기기에서 접근할 수 있게 했다.
- `start-lan.ps1`로 로컬 IP를 확인하며 백엔드와 프론트를 실행할 수 있다.
- LAN의 일반 HTTP에서는 브라우저 마이크가 차단되므로 `start-secure-phone.ps1`로 Cloudflare Quick Tunnel HTTPS 주소를 만들 수 있다.
- Cloudflare 실행 파일은 `.tools/`에 저장하고 Git에서 제외한다.

## 3. 2026-09-17 작업

### 3.1 핵심 상황 시나리오 보강

- AI 채팅에서 사용자의 명시적인 일정 등록·수정 요청을 해석해 실제 개인 일정 또는 아이 일정 API에 반영한다.
- `퇴근 18시`처럼 한 시점만 의미하는 일정은 종료시간 없이 등록할 수 있게 했다. 프론트 입력, 채팅 도구, DB 저장과 충돌 검사에서 동일하게 처리한다.
- 긴급 도움 요청 사유를 수기뿐 아니라 브라우저 마이크 녹음과 음성 인식으로 입력할 수 있게 했다.
- OCR 검토 화면에서 사용자 혼란을 줄 수 있는 `신뢰도 낮음/높음` 문구를 제거했다. 원문 근거와 수정 기능은 유지한다.
- 아이 일정이 등록되면 일정에 연결된 돌봄 항목을 만들고 가능한 가족을 즉시 추천한다.
- 요청자 본인도 일정 충돌이 없으면 `내가 맡기`로 바로 확정할 수 있다. 다른 가족은 요청 → 수락 → 주돌봄자 최종 확정 순서로 처리한다.
- 여러 가족에게 동시에 요청할 수 있고, 후보가 수락하면 주돌봄자가 최종 담당자를 확정한다. 전원이 거절하면 주돌봄자에게 다시 대안을 찾도록 알린다.
- 일정 변경으로 기존 배정이 깨지면 재배정 필요 상태와 알림을 만들고 새 후보를 추천한다.
- 아이가 여러 명일 때 같은 담당자가 시간상 함께 돌볼 수 있으면 같은 사람을 우선 추천하고, 충돌하면 다른 후보를 제시한다.
- 응답이 없는 배정 요청에는 추가 앱 알림을 만들고, Pro 가족은 추후 가전 전송에 사용할 `device_notification_outbox` 기록도 생성한다.

### 3.2 일정·알림·구성원 상태 정리

- 개인 일정과 아이 일정 모두 등록 후 수정·삭제할 수 있다. 반복 일정에서 수정·삭제하면 현재 선택한 한 건만 처리한다.
- 아이 일정의 요청·수락 결과는 알림, 캘린더, 오늘 할 일과 배정 화면에서 같은 상태를 사용한다.
- 구성원 퇴장과 자진 나가기 외에 주돌봄자 권한을 다른 활성 구성원에게 이전하는 API와 검증을 추가했다.
- 초대 링크는 한 사람이 참가한 뒤에도 만료 전까지 다른 가족이 계속 사용할 수 있다. 새 링크를 만들어도 기존 유효 링크를 즉시 폐기하지 않는다.
- 돌봄 제도 검색 지역은 주돌봄자만이 아니라 구성원별로 따로 저장한다. 지역 입력 칸에는 예시 지역을 기본값으로 넣지 않는다.

### 3.4 우리집 기록함

- 다른 서비스와 이름이 겹치던 `패밀리 앨범`을 `우리집 기록함`으로 변경하고 가족 탭으로 이동했다.

- 핵심 상황 테스트: 채팅 일정 등록·변경, 종료시간 없는 일정, 긴급 요청 음성, 다중 요청 최종 확정, 전원 거절, 미응답 재알림·가전 outbox, 여러 아이의 동일 담당자 추천 통과.
- Figma 모바일 화면 검사: OS 상태바 제거, 393×852 프레임, 헤더·알림·프로필, 하단 5개 탭 순서와 활성 색상 통과.
- 실제 공공데이터 호출: 은평구 제공기관 1건, 가구소득 18건, 건강보험료 151건 조회 성공.
- Git `diff --check` 통과.
- `backend/.env`는 `.gitignore`에 의해 추적되지 않음.

## 6. 반드시 주의할 점

1. **비밀값**: `backend/.env`, DB 비밀번호, OpenAI 키, OAuth Secret, 공공데이터 키를 커밋하거나 화면에 출력하지 않는다. `.env.example`에는 변수명만 둔다.
2. **인증**: `LGDX_REQUIRE_AUTH=0`인 로컬 데모에서는 토큰이 없을 때 기존 데모 가족이 열릴 수 있다. 운영·공개 시험에서는 인증 강제와 ThinQ 계정 연결이 필요하다.
3. **푸시 알림**: 현재는 DB 알림과 앱이 열려 있을 때의 브라우저 알림이다. 앱이 완전히 닫힌 상태의 네이티브 푸시·Web Push·ThinQ 푸시는 아직 없다.
4. **캘린더**: 코드와 설정 감지는 완료됐지만 Google·Microsoft 콘솔 콜백 등록, 실제 계정 로그인·동의, 토큰 만료 후 재연결은 개발자 계정으로 최종 확인해야 한다.
5. **공공데이터 기준연도**: 가구소득·보험료 API가 돌려주는 최신 행의 기준연도는 현재 2020년이다. 이를 2026년 현행 지원 기준으로 표현하면 안 된다. 실제 지원 여부는 공식 신청 심사로 결정된다.
6. **돌봄 제도 필터**: 서비스명과 목적 요약을 이용한 규칙 필터다. 성인 제도 혼입은 크게 줄였지만 명칭이 모호한 아동 제도가 누락될 수 있으므로 정책 담당자의 표본 검수가 필요하다.
7. **사진 저장**: 현재 앨범 사진을 DB에 저장하므로 운영 규모가 커지면 오브젝트 스토리지, 접근 URL, 썸네일, 보관기간과 삭제 정책이 필요하다.
8. **PostgreSQL 이전**: 마이그레이션 전 쓰기 작업을 멈추고 SQLite 백업을 보관한다. 실행 후 테이블별 행 수와 사진·OAuth 데이터 접근을 확인한다.
9. **임시 HTTPS 주소**: Quick Tunnel 주소는 임시 공개 주소다. 실제 가족 정보나 비밀값을 넣지 말고 시험 후 프로세스를 종료한다.
10. **마이크**: 브라우저 직접 녹음은 `localhost` 또는 HTTPS와 사용자 권한이 필요하다. 같은 Wi-Fi의 HTTP 주소에서는 녹음이 차단될 수 있다.
11. **요금제**: 토스 결제위젯 키는 7,900원 1개월 이용권 결제를 처리한다. 월 자동 갱신에는 토스 자동결제 계약과 API 개별 연동 키가 필요하며, 운영 전 웹훅·환불·빌링키 암호화를 추가해야 한다. 개발자 Free/Pro 전환은 실제 결제가 아닌 테스트용이다.
12. **에이전트 자동 실행**: 추천과 해석은 자동화하지만 배정 확정, 긴급 요청, 민감한 상태 변경은 사람의 요청·수락을 거친다.
13. **주돌봄자 탈퇴**: 주돌봄자는 먼저 활성 구성원에게 소유권을 이전해야 나갈 수 있다. 이전 대상과 현재 세션을 다시 확인한 뒤 탈퇴한다.
14. **기존 CI 오류**: 현재 `.github/workflows/ci.yml`은 저장소에 없으므로 이번 푸시에서 OAuth `workflow` 권한 오류 대상이 아니다. 나중에 워크플로 파일을 추가하려면 GitHub 인증에 `workflow` 권한이 필요하다.

## 8. 실행 명령

백엔드:

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

프론트엔드:

```powershell
cd frontend
npm install
npm run dev
```

같은 Wi-Fi 기기에서 화면 확인:

```powershell
.\start-lan.ps1
```

휴대폰 마이크까지 HTTPS로 확인:

```powershell
.\start-secure-phone.ps1
```

```powershell
cd backend
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

cd ..\frontend
npm run lint
npm run build
node scripts\visual-check.mjs
```

## 9. 이번 커밋 권장안

현재 변경은 백엔드, 프론트, DB, 외부 API, Figma UI와 문서가 하나의 통합 흐름으로 연결돼 있다. 한 번에 커밋한다면 다음 제목을 권장한다.

```text
feat: Figma UI와 가족 돌봄 에이전트 흐름 통합
```

권장 커밋 본문:

```text
- ThinQ 진입과 5개 탭을 Figma 화면 관계에 맞게 재구성
- 일정 등록·변경, 배정 추천·요청·확정과 재알림 시나리오 보강
- 음성 입력, 우리집 기록함, Google·Outlook OAuth 연결
- 토스 7,900원 결제와 구독 취소·재개 흐름 추가
- PostgreSQL·지역 돌봄 공공데이터와 통합 테스트 보강
```

명령 예시:

```powershell
git status --short
git add -A -- . ':(exclude)목업이미지.fig'
git status --short
git commit -m "feat: Figma UI와 가족 돌봄 에이전트 흐름 통합" -m "일정·배정·인수인계·기록함·결제·캘린더·공공데이터 연동과 모바일 UI 검증을 추가"
git push origin main
```

`목업이미지.fig`는 약 73MB의 원본 디자인 파일이라 위 예시에서는 제외했다. 팀 저장소에 원본을 함께 보관하기로 했다면 GitHub 파일 크기 제한과 저장소 용량을 확인하고 Git LFS 사용 여부를 먼저 결정한다. 변경량이 크므로 리뷰 단위를 나눌 수 있다면 `백엔드·DB`, `프론트·에셋`, `문서·검증` 세 커밋이 더 좋다.
