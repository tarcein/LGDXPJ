- `DATABASE_URL`이 있으면 PostgreSQL, 없으면 로컬 SQLite를 사용하는 연결 계층을 추가했다.
- 기존 SQLite 데이터를 PostgreSQL로 복사하는 `backend/scripts/migrate_sqlite_to_postgres.py`를 추가했다.
- 아이 일정, 반복 일정, 미디어, 지역, 캘린더 OAuth 상태와 연결 정보 등을 저장하도록 스키마를 확장했다.
- 주요 신규 테이블은 `family_location`, `child_schedule`, `media_asset`, `calendar_oauth_state`, `calendar_connection`이다.
- 알림에 `action_type`, `action_id`, 배정에 `requested_by_member_id`, 인수인계에 `special_note` 등을 추가했다.
- 운영 데이터 이전 여부는 마이그레이션 실행 로그와 PostgreSQL 행 수를 별도로 확인해야 한다. 스크립트가 존재한다는 사실만으로 실제 운영 데이터 이전 완료를 의미하지 않는다.

### 2.12 로컬·휴대폰 실행 지원

- Vite 개발 서버를 `0.0.0.0:5173`에서 실행해 같은 Wi-Fi 기기에서 접근할 수 있게 했다.
- `start-lan.ps1`로 로컬 IP를 확인하며 백엔드와 프론트를 실행할 수 있다.
- LAN의 일반 HTTP에서는 브라우저 마이크가 차단되므로 `start-secure-phone.ps1`로 Cloudflare Quick Tunnel HTTPS 주소를 만들 수 있다.
- Cloudflare 실행 파일은 `.tools/`에 저장하고 Git에서 제외한다.

## 5. 반드시 주의할 점

1. **비밀값**: `backend/.env`, DB 비밀번호, OpenAI 키, OAuth Secret, 공공데이터 키를 커밋하거나 화면에 출력하지 않는다. `.env.example`에는 변수명만 둔다.
2. **인증**: `LGDX_REQUIRE_AUTH=0`인 로컬 데모에서는 토큰이 없을 때 기존 데모 가족이 열릴 수 있다. 운영·공개 시험에서는 인증 강제와 ThinQ 계정 연결이 필요하다.
3. **푸시 알림**: 현재는 DB 알림과 앱이 열려 있을 때의 브라우저 알림이다. 앱이 완전히 닫힌 상태의 네이티브 푸시·Web Push·ThinQ 푸시는 아직 없다.
4. **캘린더**: 코드와 설정 감지는 완료됐지만 Google·Microsoft 콘솔 콜백 등록, 실제 계정 로그인·동의, 토큰 만료 후 재연결은 개발자 계정으로 최종 확인해야 한다.
5. **공공데이터 기준연도**: 가구소득·보험료 API가 돌려주는 최신 행의 기준연도는 현재 2020년이다. 이를 2026년 현행 지원 기준으로 표현하면 안 된다. 실제 지원 여부는 공식 신청 심사로 결정된다.
6. **돌봄 제도 필터**: 서비스명과 목적 요약을 이용한 규칙 필터다. 성인 제도 혼입은 크게 줄였지만 명칭이 모호한 아동 제도가 누락될 수 있으므로 정책 담당자의 표본 검수가 필요하다.
7. **사진 저장**: 현재 앨범 사진을 DB에 저장하므로 운영 규모가 커지면 오브젝트 스토리지, 접근 URL, 썸네일, 보관기간과 삭제 정책이 필요하다.
8. **PostgreSQL 이전**: 마이그레이션 전 쓰기 작업을 멈추고 SQLite 백업을 보관한다. 실행 후 테이블별 행 수와 사진·OAuth 데이터 접근을 확인한다.
9. **임시 HTTPS 주소**: Quick Tunnel 주소는 임시 공개 주소다. 실제 가족 정보나 비밀값을 넣지 말고 시험 후 프로세스를 종료한다.
10. **마이크**: 브라우저 직접 녹음은 `localhost` 또는 HTTPS와 사용자 권한이 필요하다. 같은 Wi-Fi의 HTTP 주소에서는 녹음이 차단될 수 있다.
11. **요금제**: Pro 상품은 출시된 상태로 표시하지만 실제 결제·구독 검증 API는 아직 없다. 개발자 모드 전환은 테스트용이다.
12. **에이전트 자동 실행**: 추천과 해석은 자동화하지만 배정 확정, 긴급 요청, 민감한 상태 변경은 사람의 요청·수락을 거친다.
13. **주돌봄자 탈퇴**: 소유권 이전 기능이 없으므로 주돌봄자는 현재 방을 나갈 수 없다.
14. **기존 CI 오류**: 현재 `.github/workflows/ci.yml`은 저장소에 없으므로 이번 푸시에서 OAuth `workflow` 권한 오류 대상이 아니다. 나중에 워크플로 파일을 추가하려면 GitHub 인증에 `workflow` 권한이 필요하다.

## 8. 이번 커밋 권장안

현재 변경은 백엔드, 프론트, DB, 외부 API, 실행 스크립트와 문서가 하나의 통합 흐름으로 연결돼 있다. 한 번에 커밋한다면 다음 제목을 권장한다.

```text
feat: 가족 돌봄 워크플로와 외부 연동 통합
```

권장 커밋 본문:

```text
- 홈·케어·일정·가족·더보기 UI와 반복 일정 흐름 개선
- 가족 초대, 배정 추천, 요청 알림과 완료 인수인계 연결
- 음성 입력, 패밀리 앨범, Google·Outlook OAuth 추가
- PostgreSQL과 지역 돌봄 공공데이터 연동
- 모바일 실행 스크립트와 통합 테스트 보강
```

명령 예시:

```powershell
git status --short
git add .
git commit -m "feat: 가족 돌봄 워크플로와 외부 연동 통합" -m "일정·가족 초대·배정·인수인계·앨범·캘린더·공공데이터·PostgreSQL 연동과 검증을 추가"
git push origin main
```

변경량이 크므로 리뷰 단위를 나눌 수 있다면 `백엔드·DB`, `프론트·에셋`, `문서·검증` 세 커밋이 더 좋다. 현재처럼 하루 작업을 한 번에 남겨야 한다면 위 통합 커밋명을 사용해도 범위를 충분히 설명한다.
