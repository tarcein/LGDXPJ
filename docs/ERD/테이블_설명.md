# ERD 테이블 설명

이 문서는 요구사항 논리 ERD의 27개 객체가 무엇을 저장하고 어떤 테이블과 연결되는지 설명한다. 전체 컬럼과 키는 [`00_요구사항_논리_ERD.dbml`](./00_요구사항_논리_ERD.dbml)에서 확인할 수 있다.

## 전체 흐름

```text
가족 그룹
├─ 구성원·자녀·권한·세션
├─ 개인 일정·아이 일정·외부 캘린더
├─ 돌봄 원문 → 돌봄 항목 → 담당 배정 → 예외·인수인계·긴급 요청
├─ 알림·푸시·가전 알림
├─ AI 대화·기능 사용량
└─ 혜택 검색·구독·결제
```

## A. 가족·구성원·자녀

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `family_group` | 하나의 가족방을 나타내는 최상위 데이터 경계다. 가족 이름과 현재 요금제를 저장한다. | 대부분의 업무 테이블이 `family_id`로 연결된다. |
| `family_location` | 가족 공통으로 사용하는 활동·거주 지역을 저장한다. 가족 단위 돌봄 제도 검색에 사용한다. | `family_group`과 1:0..1 관계다. |
| `family_member` | 가족방에 참여하는 부모·조부모·돌봄 참여자의 이름, 역할, 상태 및 주돌봄자 여부를 저장한다. | 한 `family_group`에 여러 구성원이 속한다. 일정·배정·권한·알림 등의 기준이 된다. |
| `child` | 가족이 돌보는 자녀의 이름, 나이 표기 및 프로필 사진 정보를 저장한다. | 한 `family_group`에 여러 자녀가 속하며 아이 일정·돌봄 정보·사진과 연결된다. |

## B. 인증·초대

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `family_invite_link` | 가족방 참여에 사용하는 재사용 초대 코드와 그 코드를 포함한 공유 링크를 관리한다. DB에는 원본 코드가 아닌 해시값을 저장한다. | 초대 대상 `family_group`과 발급한 `family_member`에 연결된다. |
| `family_session` | 로그인 상태를 유지하기 위한 세션 토큰 해시, 만료일시 및 마지막 접속일시를 저장한다. | 하나의 `family_group`과 그 안의 한 `family_member`를 인증한다. |

## C. 일정

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `personal_schedule` | 가족 구성원 개인의 근무·루틴 일정을 저장한다. 반복 일정과 Google·Microsoft 외부 일정도 함께 관리한다. | `family_member`가 소유하며 `family_group`에 속한다. 외부 일정 식별 조합으로 중복 동기화를 막는다. |
| `child_schedule` | 자녀의 학교·학원·방과후·활동 일정을 저장한다. 수기 등록과 알림장에서 추출된 일정을 구분한다. | 한 `child`와 `family_group`에 연결되고 `care_item`의 근거가 될 수 있다. |

## D. 돌봄 처리 파이프라인

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `care_intake` | 알림장 텍스트나 사진 OCR 결과처럼 시스템에 처음 들어온 돌봄 정보 원문을 저장한다. | 선택적으로 `child`를 지정하며, 하나의 원문에서 여러 `care_item`이 만들어질 수 있다. |
| `care_item` | 원문을 일정·변경·준비물·숙제·할 일 단위로 구조화한 항목을 저장한다. 검토·확인·배정·완료 상태도 관리한다. | 선택적으로 `care_intake`, `child`, `child_schedule`과 연결되며 여러 배정의 대상이 된다. |
| `care_assignment` | 하나의 돌봄 항목을 특정 가족 구성원에게 맡긴 기록이다. 제안·수락·거절·완료 상태와 요청·응답·완료 시간을 저장한다. | `care_item`과 담당 `family_member`를 연결하는 배정 객체다. |
| `care_exception` | 일정 충돌이나 담당 불가 상황에서 발생한 문제와 대체 담당자 제안을 저장한다. | 기존 `care_assignment`와 대체 `family_member`에 연결된다. |
| `care_handoff` | 담당자가 바뀔 때 이전 담당자가 다음 담당자에게 전달하는 브리핑과 특이사항을 저장한다. | 하나의 `care_assignment`에 대해 전달자·수신자 `family_member`를 연결한다. |

## E. 알림·설정

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `notification` | 앱에서 보여주는 알림의 제목, 본문, 중요도, 읽음 여부와 관련 화면·객체 정보를 저장한다. | `family_group`에 속하며 특정 `family_member` 대상이거나 가족 공용일 수 있다. |
| `family_data_permission` | 구성원별로 일정 상세, 위치, 건강, 사진 등의 정보 공개 허용 여부를 저장한다. | `family_member`와 공개 범위 `scope`의 조합으로 한 설정을 식별한다. |
| `notification_preference` | 구성원의 앱 알림, 하루 모아보기, TV 가전 알림 수신 설정을 저장한다. | `family_member`당 하나만 존재한다. |

## F. 사용량·AI

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `daily_usage` | OCR 횟수나 AI 채팅 토큰처럼 요금제별 한도를 적용할 기능의 누적 사용량을 저장한다. | `family_group` 단위로 기능명과 기준 시점을 묶어 집계한다. AI 채팅은 24시간 롤링 윈도우를 사용한다. |
| `assistant_message` | 사용자와 AI가 주고받은 메시지의 역할, 내용 및 발생일시를 저장한다. | `family_group`에 속하면서 구성원별 개인 대화로 분리된다. |

## G. 긴급·미디어·디바이스

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `emergency_request` | 맡은 돌봄을 수행하기 어려울 때 보내는 긴급 도움 요청과 수락·취소·해결 상태를 저장한다. | 대상 `care_assignment`, 요청자 및 선택적인 수락 `family_member`와 연결된다. |
| `media_asset` | 알림장 사진, 돌봄 완료 인증 사진, 가족 앨범 사진의 파일 정보와 저장 경로를 관리한다. | `family_group`에 속하며 선택적으로 `child`, `care_assignment`, 업로더 `family_member`와 연결된다. |
| `device_alert_outbox` | TV 등 연결 가전으로 전달할 알림을 발송 전 대기 상태로 저장하는 큐다. | 대상 `family_member`와 선택적인 `care_assignment`에 연결된다. |
| `push_device_token` | 모바일 푸시 알림을 보내기 위한 Android 기기 토큰과 등록·갱신일시를 저장한다. | 하나의 `family_member`와 `family_group`에 연결된다. |

## H. 혜택·구독·결제

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `member_benefit_location` | 구성원별로 돌봄 제도를 검색할 시/도와 구/군을 저장한다. 가족 공통 지역과 별도로 개인별 검색 지역을 지원한다. | `family_group`과 `family_member`의 조합당 하나만 존재한다. |
| `family_subscription` | 가족방의 유료 구독 상태, 금액, 결제 주기, 자동결제 키, 해지 예약 및 갱신 실패 정보를 저장한다. | `family_group`당 하나만 존재한다. |
| `payment_transaction` | 결제 요청과 승인 결과를 주문 단위로 저장하는 거래 이력이다. | `family_group`에 속하며 주문 ID로 각 결제를 식별한다. |

## I. 캘린더 연동

| 테이블 | 의미 | 주요 연결 |
| --- | --- | --- |
| `calendar_oauth_state` | Google·Microsoft 캘린더 OAuth 연결을 시작할 때 위조 요청을 막기 위한 임시 상태값과 만료 정보를 저장한다. | 연결을 요청한 `family_group`, `family_member`, 제공자에 연결되며 인증 완료 후 삭제된다. |
| `calendar_connection` | 외부 캘린더 연결에 필요한 액세스·리프레시 토큰, 만료일시 및 마지막 동기화일시를 저장한다. | 가족 ID·구성원 ID·제공자 조합당 하나만 존재한다. |

## 구현 물리 ERD에만 있는 테이블

아래 두 테이블은 실제 DB에는 존재하지만 요구사항 논리 ERD 27개에서는 제외한다.

| 테이블 | 의미 | 제외 이유 |
| --- | --- | --- |
| `family_invite_code` | 이전 버전의 초대 코드 해시와 만료일시를 저장하던 테이블이다. | 현재 신규 초대는 `family_invite_link`만 사용하므로 레거시 호환용이다. |
| `plan_preview` | 결제 없이 가족방의 Free/Pro 상태를 바꿔보는 개발자 미리보기 상태를 저장한다. | 운영 업무 데이터가 아닌 개발·데모 전용 데이터다. |

## 핵심 ERD 12개

발표용 [`02_MVP_핵심기능_ERD.dbml`](./02_MVP_핵심기능_ERD.dbml)은 전체 27개 중 다음 중심 객체만 보여준다.

```text
family_group, family_member, child,
personal_schedule, child_schedule,
care_intake, care_item, care_assignment,
care_exception, care_handoff, emergency_request, notification
```
