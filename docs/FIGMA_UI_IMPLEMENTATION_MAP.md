## `family-care-ui` 레퍼런스 사용

- 독립 React 18/Tailwind 프리뷰 앱과 하드코딩 더미 데이터는 합치지 않는다.
- `NotificationList`의 Figma 구조(범위 탭, 날짜 그룹, 모두 읽음, 빈 상태)를 현재 `notifications` 화면에 이식하고 실제 bootstrap 알림 및 읽음 API에 연결했다.
- 공통 색상·카드·토글 규칙은 현재 최신 Figma 토큰 및 기존 CSS 컴포넌트와 대조하는 참고값으로 사용한다.
- 해당 폴더의 하단 메뉴는 구형 `홈·디바이스·케어·가족·메뉴` 구조이므로 최신 `홈·케어·일정·가족·더보기` 내비게이션을 대체하지 않는다.
