# LG 가족 운영 에이전트 메뉴구조도 기준

이 문서는 `기능요구사항명세서.md`, `PRD_MVP_AI가족운영에이전트.md`, `유스케이스명세서.md`를 근거로 작성한 UX 정보구조 기준 문서다.

## 설계 원칙

- 앱 진입점은 `홈`으로 두고, 사용자가 찾는 목적 기준으로 1Depth를 구성한다.
- 기능 내부의 버튼·입력 항목·팝업·세부 동작은 메뉴구조도에서 제외한다.
- 기존 기능요구사항 화면 코드 S1~S19를 모두 유지한다.
- 다이어그램에서 사용할 안정적인 화면 식별자로 `SCR-001`~`SCR-019`를 부여하고, 기존 화면 코드(S1~S19)와 함께 기록한다.
- MVP 범위는 PRD의 Phase 1/Phase 2와 서비스 운영에 필요한 기반 화면을 기준으로 구분한다.

## MVP 범위 기준

| 범위 | 의미 | 화면 |
|---|---|---|
| MVP 핵심 | Family Inbox·Role Match의 핵심 경험 | S5, S6 |
| MVP 필수 기반 | 로그인 후 MVP를 사용하기 위해 필요한 가족·일정·대시보드·알림·권한·완료·플랜 기반 | S1, S2, S3, S4, S11, S12, S13, S14, S19 |
| MVP 이후 | Care Handoff·Exception Care 및 부가 서비스 | S7, S8, S9, S10, S15, S16, S17, S18 |

## 화면 코드 출처

S1~S19 화면명은 `기능요구사항명세서.md`의 `0. 관련 화면 목록`을 그대로 사용했다. FR ID는 같은 문서의 각 기능 요구사항 표에서 해당 화면에 연결된 ID를 매핑했다. 홈 대시보드(S3)는 기능 요구사항 표에 직접 연결된 행이 없어, 대시보드에 집계되는 핵심 기능 ID를 `집계`로 표시했다.
