# ZIPPY 화면설계서 (통합본)

> LG ThinQ 기반 AI 가족 돌봄 운영 에이전트 서비스 **ZIPPY**의 전체 화면(15장)을 화면별 목적·구성요소·동작 규칙·연동 API 기준으로 정리한 문서입니다.
> 각 화면의 번호(①~)는 화면 캡처에 표시된 빨간 번호와 1:1로 대응합니다.

---

## 0. 서비스 한눈에 보기

| 구분 | 내용 |
|---|---|
| 서비스 | ZIPPY — 흩어진 돌봄 정보를 모아 **누가·언제·무엇을** 맡을지 가족이 함께 조율하는 AI 가족 운영 에이전트 |
| 진입 | LG ThinQ 앱 홈의 ZIPPY 카드 → 가족방 선택 → 홈 (별도 앱 설치·재로그인 없음) |
| 주 사용자 | 주돌봄자(부모)·제2돌봄자·조부모/친척·기타 돌봄자(시터 등) — 역할에 따라 보이는 정보와 알림이 자동으로 달라짐 |
| 핵심 흐름 | ① 가족방·아이 등록 → ② 알림장(사진/문자) 등록 → ③ AI가 일정·준비물·숙제로 정리 → ④ 담당자 추천·요청·수락·확정 → ⑤ 충돌·긴급 시 대안 승인 → ⑥ 완료·인수인계 → ⑦ 앱·가전(TV/정수기)으로 알림 |
| 플랜 | Free(무료) / Pro(월 7,900원) — 긴급 도움 요청, 가전 알림, 돌봄 공백 예측, 돌봄 제도 안내, 모음ZIP 등은 Pro |

### 화면 구성 원칙

- **하단 탭 5개**(홈·케어·일정·가족·더보기)로 모든 화면에 접근하며, 하위 화면에서도 소속 탭이 강조됩니다.
- **상단 헤더**: 가족방 이름(누르면 가족방 전환) · 알림 벨(미확인 수 배지) · 프로필(내 정보 공개 설정).
- **케어 어시스턴트(AI)** 버튼이 모든 화면 우측 하단에 떠 있어 어느 화면에서든 자연어·음성으로 질의할 수 있습니다.
- **"평소와 같은 배정은 알리지 않고, 달라질 때만 알린다"** 를 알림 설계의 기본 원칙으로 합니다.
- Pro 전용 기능은 Free 사용자에게 `PRO` 라벨로 표시하고, 누르면 플랜 안내(SCR-12)로 이동합니다.

### SCR-01. 서비스 진입·가족방 선택·홈

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-01 |
| 화면 이름 | 서비스 진입·가족방 선택·홈 |
| 관련 유스케이스 | UC-01~UC-10 공통 선행(가족방 진입), UC-07 |
| 관련 기능 요구사항 | FR-001, FR-011, FR-029 |
| 이용 플랜 | Free / Pro 공통 |
| 주 사용자 | ThinQ 로그인 사용자 · 가족방 구성원 |
| 메뉴 경로 | ThinQ 앱 홈 → ZIPPY 카드(더 알아보기) 또는 홈 선택 → 가족방(민솔이네 집) → ZIPPY 홈 |
| 화면 개요 | ThinQ 앱에서 ZIPPY 가족방을 선택하면 별도 로그인 없이 오늘의 돌봄 요약(홈)까지 자연스럽게 진입한다. 홈 선택 시트로 ThinQ 일반 홈과 가족방을 언제든 오갈 수 있다. |
| 연동 API | GET /api/families/me · GET /api/bootstrap |

**화면 구성**

| No. | UI 요소 | 화면 설명 |
|---|---|---|
| ① | [ThinQ 홈] 홈 선택 · ZIPPY 안내 카드 | • 좌측 상단 "이지윤 홈 ∨"을 누르면 홈 선택 시트가 열린다.<br>• 하단 안내 카드의 [더 알아보기]로 ZIPPY에 진입한다. 가족방이 이미 있으면 서비스 진입 로딩 후 홈으로, 없으면 홈 선택 시트의 [지금 만들기]로 온보딩(SCR-02)으로 이동한다. |
| ② | [가족방 선택] 홈 선택 시트 | • 시트에 ThinQ 일반 홈(이지윤 홈)과 ZIPPY 가족방(민솔이네 집)이 구분되어 표시되고, 현재 선택한 홈에 체크가 표시된다.<br>• 가족방을 선택하면 짧은 서비스 진입 로딩(약 1초) 후 ZIPPY 홈으로 전환된다.<br>• 시트 바깥을 누르면 닫힌다. |
| ③ | [ZIPPY 홈] 가족명 헤더 | • 가족방 이름(민솔이네 집 ∨)과 날짜·구성원 요약을 보여준다.<br>• 누르면 홈 선택 시트가 다시 열려 다른 가족방/ThinQ 홈으로 전환할 수 있다. |
| ④ | 알림 벨 · 프로필 | • 벨: 읽지 않은 알림 개수를 배지로 표시하고, 누르면 알림함(SCR-11)으로 이동한다.<br>• 프로필(이니셜 아바타): 내 정보 공개 범위 설정(SCR-10)으로 이동한다. |
| ⑤ | 진행 중 돌봄 배너 | • 지금 진행 중인 돌봄(예: 방과후 수학 하원)과 담당자를 빨간 배너로 보여준다.<br>• 누르면 오늘의 역할 배정(SCR-05)으로 이동한다. 진행 중인 배정이 없으면 표시하지 않는다. |
| ⑥ | 하단 탭바 | • 홈 · 케어 · 일정 · 가족 · 더보기 5개 탭. 현재 탭은 브랜드 레드로 강조된다.<br>• 하위 화면에서도 소속 탭이 강조 상태를 유지한다. |

**Check Point**
- 가족방(세션) 유무에 따라 진입이 분기된다: 있음 → 서비스 로딩 → 홈, 없음 → 홈 선택 시트 → 온보딩.
- 홈 상단의 확인 필요 배너는 "확인 N건"이 있을 때만 나타나며, 평소와 같은 배정은 알리지 않는다.
- ThinQ 홈은 시연 환경에서 목업 화면으로 구성하며, 실제 ThinQ 앱에서는 서비스 진입점(카드)으로 교체된다.

| 항목 | 내용 |

| 화면 ID | SCR-02 |
| 화면 이름 | 주돌봄자 온보딩 |
| 관련 유스케이스 | UC-03(역할 설정), UC-01~UC-10 공통 선행(가족방 생성) |
| 관련 기능 요구사항 | FR-001, FR-003 |
| 이용 플랜 | Free / Pro 공통 |

| 메뉴 경로 | 처음 진입 → 가족방 만들기 → 내 역할 선택 → 아이 등록 → (가족 초대) → 홈 |
| 화면 개요 | 가족방·내 역할·아이 정보를 최소한의 입력으로 등록해 서비스 사용 준비를 마친다. 아이 일정과 루틴은 가족방 진입 후 캘린더에서 등록하도록 미뤄 온보딩 부담을 줄인다. |
| 연동 API | POST /api/families · POST /api/children · POST /api/families/join(초대코드 참가) |

**화면 구성**

| No. | UI 요소 | 화면 설명 |
|---|---|---|
| ① | [가족방 만들기] 입력 영역 | • 상단 탭으로 [가족방 만들기] / [초대코드로 참가]를 전환한다.<br>• 가족방 이름(예: 민솔이네 집)과 내 이름을 입력하고 [가족방 만들기]를 누르면 가족방과 주돌봄자 계정이 함께 생성된다.<br>• 필수값이 비어 있으면 버튼이 비활성화된다.<br>• 이미 가입된 가족방이 있으면 [현재 가족방으로 돌아가기]로 되돌아갈 수 있다. |
| ② | [내 역할 선택] 역할 카드 | • 주양육자(전체 가족 캘린더 풀뷰) · 제2양육자(업무 캘린더 동기화 + 내 배정) · 조부모/친척(오늘 내게 배정된 태스크 카드만) · 기타 돌봄자(시터·돌봄선생님) 중 1개를 선택한다.<br>• 역할에 따라 보이는 정보와 알림이 자동으로 정해지며 나중에 바꿀 수 있다.<br>• 상단 진행 바(1/4)와 ‹ 버튼으로 이전 단계로 돌아갈 수 있다. |
| ③ | [아이 등록] 정보 입력 카드 | • 프로필 사진(선택, JPG/PNG/WebP), 이름, 생년월일·나이·기관(예: 만 7세 · 한빛초등학교)을 입력한다.<br>• [+ 자녀 추가]로 여러 아이를 등록하면 등록된 아이가 목록으로 쌓이고 ×로 삭제할 수 있다.<br>• 안내 카드: "일정은 가족방에서 등록해요 — 가족방에 들어간 뒤 캘린더의 ＋ 버튼에서 아이 일정과 루틴을 추가할 수 있어요." |
| ④ | [다음] 버튼 | • 입력한 아이 정보를 저장하고 가족 초대 단계(4/4)로 이동한다.<br>• 초대 단계에서는 링크·코드를 공유하거나 [나중에 할게요]로 건너뛰고 홈에 진입한다. |

**Check Point**
- 가족방을 만든 사람은 자동으로 **주돌봄자(가족방 소유자)** 가 되며 결제·구성원 퇴장·소유권 이전 권한을 가진다.
- 무료 플랜은 보호자(주돌봄자+참여 가족) 최대 3명, 아이 최대 2명까지 등록되며, 초과 시 Pro 전환을 안내한다(FR-003).
- 아이 정보는 이름·나이·기관 등 서비스 운영에 필요한 최소 항목만 수집한다.
- 초대 단계 안내: "ZIPPY에 초대해도 가전 제어 권한은 따라가지 않습니다"(권한 분리 원칙).

| ③ | [알림 안내] 알림 원칙 | • "중요한 순간에만 알려드려요"라는 제목 아래 알림 강도를 3단계로 예시한다.<br>  - 픽업 담당자가 필요할 때 → 즉시 알림<br>  - 준비물이 빠졌을 때 → 출발 임박에만 진동<br>  - 그 밖의 정보 → 하루 1회 모아서<br>• "평소와 같은 배정은 알리지 않습니다. 달라질 때만 말을 겁니다." 안내 문구를 함께 노출한다. |
| ④ | [알림 허용하기] / [나중에 설정] | • [알림 허용하기]: 기기 알림 권한을 요청한 뒤 합류를 완료하고 홈으로 이동한다.<br>• [나중에 설정]: 권한 요청 없이 합류를 완료하며, 이후 더보기 → 알림 설정(SCR-14)에서 변경할 수 있다. |

**Check Point**
- 초대 링크(`?invite=코드&role=역할`)로 접속하면 초대 미리보기부터 시작하고, 초대 코드는 발급 후 7일 동안 재사용할 수 있다.
- 초대를 수락(합류)해야만 가족 데이터에 접근할 수 있다(FR-001).
- 조부모·시터 역할은 오늘 내게 배정된 태스크 중심의 단순 화면으로 시작한다.

| ⑤ | [숙제 확인] 등록 폼 | • 아이 선택 칩 · 숙제 내용 · 날짜(선택)를 입력하고 [숙제 등록]을 누르면 등록된다.<br>• 알림장 등록 없이 화면에서 직접 등록할 수 있다. |
| ⑥ | [숙제 확인] 날짜별 목록 | • 오늘 / 날짜별로 그룹화된 숙제 목록을 체크박스로 완료 처리한다.<br>• 항목을 누르면 내용·날짜를 그 자리에서 수정하고 저장할 수 있다. |

**Check Point**
- 홈은 **하나의 조회(/api/bootstrap)** 로 일정·배정·준비물·숙제·예외를 한 번에 구성한다.

**Check Point**
- 배정 상태 흐름: 수락 대기(PROPOSED) → 최종 확인 대기(CANDIDATE_ACCEPTED) → 담당 확정(ACCEPTED) → 완료(COMPLETED) / 거절 / 취소 / 재배정 필요(일정 변경 시).
- 케어 홈에는 번호 외에도 충돌 상태 띠(충돌 시 빨강 · 정상 시 초록), "내가 맡은 일" 요약(맡은 일·완료·특이사항 건수), 빠른 실행(긴급 도움 요청 · 역할 배정)이 함께 표시된다.
- 충돌 감지 시 수락됐던 배정은 재확인 상태로 바뀌고, 가능한 대체자가 있으면 대안이 자동 생성된다.

**Check Point**
- 사진은 **초대된 가족 구성원만** 열람할 수 있다(NFR-025). 업로드 형식은 JPG·PNG·WebP.

**Check Point**
- 지역은 **시·도와 시·군·구까지만 저장**하고 상세 주소는 수집하지 않는다(개인정보 최소화).

- 제도 정보는 공공데이터 기반이며 조건을 바꾸면 재검색된다. Free 사용자에게는 [Pro에서 돌봄 제도 검색]으로 안내한다.

| ④ | [방해 금지] 시간 · 무음 | • "가전 알림 끄는 시간"의 시작·종료 시각을 지정한다(기본 22:00~07:00, 자정을 넘는 구간 지원). 이 시간에는 가전 알림을 보내지 않는다.<br>• "아이 낮잠·취침 중엔 음성 끄기" 토글로 루틴의 취침 시간 기준 무음 설정을 저장한다. |
| ⑤ | [테스트 알림] 결과 · 발송 | • 우선순위 순서대로 판정한 가전과 실제 안내 문구를 결과 카드로 보여준다(예: 음성 알림 · 정수기 · "민솔이 하원 30분 전이에요.").<br>• [지금 테스트로 보내기]를 누르면 실제 알림이 생성되어 TV 화면·음성 가전에 즉시 전달된다.<br>• [TV 꺼짐 상태로 테스트]로 TV가 꺼진 상황을 가정해 다음 순위로 전환되는지 확인한다. |

**Check Point**
- TV 켜짐/꺼짐은 TV 화면이 상태(화면 표시·포커스)를 주기적으로 서버에 보고해 판정하며, 일정 시간 신호가 없으면 꺼짐으로 처리한다.
- 음성 가전은 음성 합성(TTS)으로 알림 내용을 읽어 주며, 알림 내용에 따라 문구가 실시간으로 바뀐다. 청각 알림은 고령 사용자를 고려해 음량을 조절할 수 있다(NFR-020).
- 시연 환경에서는 TV와 정수기를 각각 별도 기기(화면 · 음성 출력)로 구성해 우선순위 전환을 실제 소리·화면으로 확인한다.
- 방해 금지 시간은 즉시 적용되며, 낮잠·취침 시간 연동 자동 무음은 설정값 저장 후 고도화 단계에서 적용한다.
