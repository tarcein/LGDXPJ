# AI 가족 운영 에이전트 — 기능 요구사항 명세서 (Functional Requirements Specification)

> 본 문서는 `PRD_MVP_AI가족운영에이전트.md`, `유스케이스다이어그램.md`, `유스케이스명세서.md`의 내용을 근거로, 개발자가 구현 가능한 수준의 문장으로 기능 요구사항을 정의합니다.

| FR-020 | 긴급 요청 응답 처리 | 시스템은 긴급 요청에 최초로 응답한 가족 구성원을 담당자로 확정하고, 나머지 구성원에게는 마감을 안내해야 한다 | 중 | S9 | UC-04b (대안 흐름 A1) | 유료(FR-019에 종속). 동시 응답 시 선착순 처리 |

## 6. 돌봄 인수인계 기능 (Care Handoff, UC-05)

| 기능 ID | 기능명 | 설명 | 우선순위 | 관련 화면 | 관련 유스케이스 | 비고 |

| FR-021 | 돌봄 담당자 전환 감지 | 시스템은 배정 결과를 근거로 돌봄 담당자가 바뀌는 시점을 자동으로 감지해야 한다 | 중 | S10 | UC-05 | 무료 |
| FR-022 | 인수인계 맥락 요약·전달 | 시스템은 신규 담당자에게 해당 시점에 필요한 맥락 정보(시간, 장소, 준비물, 특이사항)만 정리해 전달해야 한다 | 중 | S10 | UC-05 | 무료. 전체 이력이 아닌 "그 시간에 필요한 것"만 필터링하는 것이 핵심 차별점 |

> **(변경) FR-024 인수인계 확인 시 위치 자동 기록 / FR-025 돌봄 동선 확인**: 초기 기획 당시 정의했던 GPS 기반 위치 자동 기록·동선 지도 기능은 실제 서비스 범위에서 제외되었습니다. 현재 인수인계 확인은 "확인했어요" 버튼 입력만으로 완료 처리되며(위치 정보 수집 없음), 관련 화면(S15 돌봄 동선 확인)도 존재하지 않습니다. 개인정보(위치정보) 수집을 최소화하는 방향으로 범위가 조정되었습니다.
