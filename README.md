# LG Family Care 개발 목업

Figma [`기능` 페이지](https://www.figma.com/design/l6KPNTjOaPSNsmCkvZR5lW/DX-%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8?node-id=413-8)의 모바일 목업과 이 폴더의 [`docs`](docs/) 요구사항을 기준으로 만든 팀 개발용 프로토타입입니다.

## 폴더와 담당 경계

| 폴더 | 역할 | 주 작업 |
|---|---|---|
| `frontend/` | React·TypeScript UI | Figma 화면, 사용자 흐름, 접근성, API 호출 |
| `backend/` | FastAPI·PostgreSQL/SQLite API | 데이터 저장, 돌봄 상태 전이, 정책, 외부 연동 어댑터 |
| `docs/` | 기획·계약 | 원본 기획 자료, [개발 범위와 API 계약](docs/개발_계약.md) |

프론트엔드와 백엔드는 `/api` 경로와 [`docs/개발_계약.md`](docs/개발_계약.md)의 상태·요청 형식으로 연결됩니다. `frontend/vite.config.ts`가 개발 중 API 요청을 `127.0.0.1:8000`으로 전달합니다. 프론트엔드는 백엔드 저장소 테이블에 직접 의존하지 않습니다.

## 로컬 실행 (PowerShell)

두 터미널을 열고 저장소 루트에서 각각 실행합니다.

```powershell
cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

```powershell
cd frontend
npm install
npm run dev
```

화면은 `http://127.0.0.1:5173`, API 문서는 `http://127.0.0.1:8000/docs`입니다. `backend/.env`에 `DATABASE_URL`이 있으면 PostgreSQL을 사용하고, 없으면 로컬 `backend/lgdx.db`를 사용합니다. `.env`와 로컬 DB 파일은 Git에 올리지 않습니다.

같은 와이파이의 휴대폰·다른 PC에서 화면만 확인하려면 `./start-lan.ps1`을 실행하고 표시되는 `http://192.168.x.x:5173` 주소를 엽니다. 브라우저 직접 마이크는 보안 정책상 LAN HTTP에서 차단됩니다. 휴대폰 음성 녹음까지 시험하려면 기존 서버를 종료한 뒤 `./start-secure-phone.ps1`을 실행하고 표시되는 임시 HTTPS 주소를 엽니다. 이 스크립트는 Cloudflare Quick Tunnel 실행 파일을 로컬 `.tools`에 받고 임시 공개 주소를 만들므로 주소를 다른 사람에게 공유하지 마세요.

## 현재 동작 범위

앱은 `홈 · 케어 · 일정 · 가족 · 더보기` 5개 탭으로 구성됩니다. `bar_asset` 아이콘은 기본 회색, 선택 탭은 브랜드 빨강으로 표시됩니다. 홈에는 아이 일정과 준비물 요약, 돌봄 배정과 알림을 분리해 보여주며, 모든 화면에서 우측 하단 AI 버튼으로 채팅을 열 수 있습니다. 상단 알림·프로필, 가족방 생성·초대코드 및 링크 참가, 구성원별 권한, 돌봄 배정·인수인계·긴급 요청, Free/Pro 개발자 미리보기가 실제 API와 DB에 연결되어 있습니다.

알림장 사진은 카메라 또는 앨범에서 실제 파일을 선택해 아이와 함께 OCR API로 전송합니다. 확인된 내용은 일정·준비물·할 일·변경으로 분류됩니다. 아이 일정은 반드시 아이를 지정하며 아이별 색상과 필터를 사용합니다. 달력 날짜를 누르면 그날 일정, 담당자, 추가 버튼이 열리고, 아이/본인 일정으로 나누어 등록합니다. 일정 날짜와 시작·종료 시간은 키보드로 직접 입력할 수 있고, 학원·방과후·운동 같은 고정 루틴은 요일과 종료일을 정해 최대 1년치까지 한 번에 등록할 수 있습니다. AI 텍스트·음성 채팅은 백엔드 OpenAI 설정을 사용합니다. 음성 버튼은 파일 선택이나 카메라를 열지 않고 브라우저 마이크로 바로 녹음하며, PC localhost 또는 HTTPS에서 동작합니다.

돌봄 담당자는 `완료 체크`에서 특이사항을 수기 또는 음성으로 남기고 완료 사진을 선택적으로 첨부합니다. 이 기록은 다음 돌봄자에게 자동으로 전달되며, 완료 사진은 가족 탭의 `우리집 기록함`에 함께 저장됩니다. 직접 올린 사진도 PostgreSQL/SQLite DB와 날짜별 폴더에 저장되어 새로고침 후 유지됩니다.

가족 초대 링크는 가족방 이름, 초대한 사람, 지정 역할을 먼저 보여줍니다. `합류할게요`를 누르면 기본 정보와 역할별 기능 안내를 거쳐 가족방에 들어갑니다. 로컬 주소로 만든 링크는 다른 기기에서 열 수 없으므로 실제 카카오톡 공유 시험에는 배포 주소나 같은 네트워크에서 접근 가능한 프론트 주소를 사용해야 합니다.

카카오톡 전용 공유창을 사용하려면 `frontend/.env.example`을 `frontend/.env`로 복사하고 `VITE_KAKAO_JAVASCRIPT_KEY`에 카카오 플랫폼의 **JavaScript 키**를 넣은 뒤 Vite를 재시작합니다. 같은 프론트 주소를 Kakao Developers의 `플랫폼 키 > JavaScript 키 > JavaScript SDK 도메인`과 `제품 링크 > 웹 도메인`에 모두 등록해야 합니다. 키가 없거나 SDK를 쓸 수 없으면 기존처럼 링크 복사·기본 공유창으로 동작합니다.

Google/Outlook 캘린더는 각각 OAuth 연결·콜백·동기화 흐름을 사용하며, `backend/.env`의 Client ID와 Secret 설정 여부에 따라 연결 버튼이 활성화됩니다. 돌봄 제도 화면은 시·도와 시·군·구까지만 저장한 뒤 보조금24에서 해당 구, 해당 시, 전국 공통 공공서비스를 구분해 가져옵니다. 다른 지자체 전용 결과는 목록에서 제외합니다. Pro 결제는 7,900원 서버 주문과 Toss 승인 검증을 거치며, 빌링키 환경에서는 월 자동 갱신과 기간 말 구독 취소·재개를 처리합니다. 현재 결제위젯 키는 자동 갱신이 없는 1개월 이용권입니다. ThinQ 계정·푸시·가전과 돌봄 공백 예측 고도화는 후속 연동 범위입니다.

## 에이전트 핵심 흐름

현재 에이전트의 중심은 `알림장·음성 인식 → 가족 일정과 돌봄 상태 파악 → 가능한 담당자 추천 → 사용자 승인 후 배정 요청 → 수락·거절·인수인계·완료 추적` 흐름입니다. 추천 단계는 요청자 자신을 제외하고 개인 일정 충돌, 같은 시간의 다른 돌봄, 현재 배정 수를 비교합니다. 에이전트가 임의로 담당자를 확정하지 않고 사람의 요청·수락을 거쳐 실행하며, 결과는 다음 추천과 인수인계에 다시 반영됩니다.

OpenAI 채팅만으로 에이전트가 되는 것은 아닙니다. 상황을 읽는 입력 도구, 가족 데이터에 근거한 판단, 배정·알림 같은 실행 도구, 사용자 승인, 실행 결과를 다시 상태로 저장하는 폐루프가 함께 있을 때 이 서비스의 에이전트성이 생깁니다. 현재 추천은 설명 가능한 규칙 기반 판단이며, 향후 평가 데이터가 쌓이면 LLM 도구 호출이나 학습 모델을 이 결정 과정에 단계적으로 넣을 수 있습니다.

이 코드는 **로컬 개발용 데모**입니다. 가족방 Bearer 세션과 일부 가족별 접근 통제가 있지만 운영용 계정 인증, 토큰 암호화·폐기, 아동 개인정보 보호, OAuth 토큰 암호화 저장은 추가 구현이 필요합니다. 실제 가족 데이터를 입력하거나 이 상태로 공개 배포하지 말고, 운영 단계에서 `docs/비기능요구사항명세서.md`의 보안·개인정보 요구사항을 적용해야 합니다.
